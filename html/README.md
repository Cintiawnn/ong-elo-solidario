# ONG Elo Solidário

Projeto acadêmico desenvolvido para praticar conceitos de desenvolvimento front-end

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git e GitHub

## Estrutura do projeto

- pasta `html` com as páginas do site
- pasta `css` com os estilos
- pasta `imagens` com os arquivos de mídia
- pasta `js` com os arquivos JavaScript

## Funcionalidades

- navegação em formato SPA
- formulário de cadastro
- armazenamento de dados com localStorage
- layout responsivo
- componentes visuais
- melhorias de acessibilidade

## Objetivo

O projeto tem como objetivo simular uma plataforma de uma ONG, permitindo apresentar projetos sociais, ações de voluntariado e cadastro de participantes
## Como executar o projeto

1. baixar ou clonar o repositório
2. abrir a pasta do projeto no VS Code
3. abrir o arquivo `html/index.html` no navegador
4. não é necessário instalar dependências externas

## Versionamento

o projeto utiliza Git e GitHub para controle de versões

foram utilizadas as branches `main`, `develop`, `feature/acessibilidade` e `hotfix/correcao`

os commits seguem mensagens simples e semânticas como `feat`, `docs` e `refactor`
