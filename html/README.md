# ONG Elo Solidário

Projeto acadêmico desenvolvido para praticar conceitos de desenvolvimento front-end

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vite
- Git
- GitHub

## Estrutura do projeto

- pasta `html` com as páginas do site
- pasta `css` com os estilos
- pasta `imagens` com os arquivos de mídia
- pasta `js` com os módulos JavaScript
- pasta `dist` com a versão de produção

## Funcionalidades

- navegação em formato SPA
- formulário de cadastro
- armazenamento com localStorage
- layout responsivo
- componentes visuais
- melhorias de acessibilidade
- código JavaScript modularizado

## Como executar

1. baixar ou clonar o repositório
2. abrir a pasta no VS Code
3. executar `npm install`
4. executar `npm run dev`
5. abrir o endereço informado pelo Vite

## Build de produção

Para gerar a versão otimizada:

npm run build

A versão final será criada na pasta `dist`

## Versionamento

O projeto utiliza Git e GitHub para controle de versões

Foram utilizadas branches para separar funcionalidades e correções

Também foram utilizados commits semânticos, issue, milestone e pull request durante o desenvolvimento
